## Description

This is a local copy of NCBI's [AMRFinderPlus](https://github.com/ncbi/amr/wiki) database, which describes antimicrobial resistance genes, stress response genes, and virulence genes.

To set it up on your computer you need to run the program <span class="artifact-p">[anvi-setup-amrfinder](/help/main/programs/anvi-setup-amrfinder)</span>, and it is required to run <span class="artifact-p">[anvi-run-amrfinder](/help/main/programs/anvi-run-amrfinder)</span>.
